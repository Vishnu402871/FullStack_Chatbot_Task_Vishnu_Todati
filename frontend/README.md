# FullStack Chatbot Task Vishnu Todati

## Project Description
A Full Stack AI Support & Lead Assistant web application built using React, TypeScript, Node.js, Express and SQLite.

## Technologies Used
- React.js
- TypeScript
- Node.js
- Express.js
- SQLite
- Bootstrap

## Features
- Customer enquiry form
- Rule-based chatbot
- Admin dashboard
- Search functionality
- Status filtering
- CRUD operations
- Database integration

## Frontend Setup

cd frontend
npm install
npm run dev

## Backend Setup

cd backend
npm install
node server.js

## Database
SQLite database used for enquiry storage.

## API Endpoints

GET /api/enquiries

POST /api/enquiries

PUT /api/enquiries/:id

DELETE /api/enquiries/:id
